## 1. Rooms & Joining

- Host creates a table → gets a room code / invite URL to share with friends (like mahjong-vtt).
- Players open the link → claim a seat (color) or watch. 3–4 players start; seats for 3 or 4.
- Settings live on the START screen (pre-game), not only in-game (user rule): setup mode (fixed/variable board), 10 VP target, turn timer (off/90s+bank à la tournament), robber-on-desert-start always on.
- <add-when-implemented> exact join/seat flow screens.

## 2. Table Setup

- **Variable setup** (default): random hex layout + spiral number discs (A–R order, desert skipped) + legal ports — all generated by the kernel; all clients see the identical board (server seed).
- **Fixed setup**: the beginner layout.
- **Opening:** each player places 2 settlements + 2 roads (round 1 order, round 2 reversed), collecting the 2nd settlement's resources. Placement UX shows legal intersections live (distance rule pre-validated by kernel).

## 3. Core Game Loop

Per turn: play 1 dev card (optional) → roll dice (animated, server-determined) → production (floating resource tokens to buildings) → if 7: discard >7 hands + mandatory robber move + steal → action phase: trade panel + build buttons (road/settlement/city/dev-card, costs shown, illegal builds disabled with reason tooltip) → end turn. Pass-the-dice turn indicator always visible.

Rules authority: the `catan-board-game` skill + official 6th Ed; kernel tests encode every branch (see docs/features/rules-kernel.md).

## 4. Actions & Interactions

- **Build:** click a legal edge/intersection; kernel validates distance rule, connectivity, costs, piece limits (15/5/4).
- **Trade:** propose panel (give/want chips); broadcasts to table; accepts/counteroffers chat-style; bank 4:1 + port trades one-click when eligible. Hidden information rule: hand sizes public, contents private (except during production/discard moments).
- **Dev cards:** private hand tray; play one/turn (not one bought this turn); knight → robber move UI; monopoly → resource picker.
- **Robber:** drag to a legal hex; victim picker if multiple; steal animation (random card).
- <add-when-implemented> mobile/touch affordances.

## 5. Winning & Post-Game

- 10 VP on your own turn → victory overlay; VP cards auto-revealed; final scoreboard (built/earned breakdown per player, rulebook-style).
- Rematch = new seed, same room; hand-history/roll log export (post-game recap card) — <add-when-implemented>.

## 6. Spectators & Reconnection

- Unseated visitors browse the table (orbit only, no acts) — mahjong-vtt pattern.
- Mid-game reconnect rehydrates full state from the room server via seat token.

## 7. Edge Cases & Error States

- Supply exhaustion: production rule ("if not enough for all, nobody collects; if only one player affected, they take the remainder") surfaced in UI.
- Robber with no buildings on hex → no theft.
- Longest Route breakage → tile moves/returns to supply, with notification.
- Dev card deck empty → purchase disabled visibly.
- Forgotten victory declaration → kernel allows claim only on own turn.
- <add-when-implemented> disconnect during pending trade/robber prompts (timeouts).

## 8. UI Standards

- Cinematic island: original-painted terrain art (CC0 pipeline), felt/wood table surround, warm-neutral lighting that preserves terrain colors (mahjong-vtt desaturation lesson).
- Resource cards readable at a glance: icon + name (not color alone — accessibility).
- All rules text is our own prose. Toasts cite the rule ("Distance Rule", "Maritime Trade 4:1").
- Accessibility: seat color + symbol, keyboard camera, reduced-motion toggle.
